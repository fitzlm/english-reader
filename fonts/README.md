# 字体

| 文件 | 来源 | 许可 |
|---|---|---|
| `Literata-{normal,italic}-{latin,latin-ext}.woff2` | [Literata](https://github.com/googlefonts/literata)（Google Fonts 提供的 latin / latin-ext 子集，可变字重与光学尺寸） | SIL OFL 1.1，见 `OFL-Literata.txt` |
| `LinguiProIPA.woff2` | [Charis SIL](https://software.sil.org/charis/) 的音标子集（基本拉丁 + IPA 扩展 + 间距修饰符 + 组合附加符号） | SIL OFL 1.1，见 `OFL-CharisSIL.txt` |

Literata 缺大部分 IPA 字形（ɪ ʃ ʒ θ ʌ ː …），音标单独用 Charis SIL 的子集显示。
子集属于 OFL 所说的修改版，而 "Charis" 与 "SIL" 是保留字体名，所以子集的字体名改成了
`LinguiPro IPA`（name 表 1/3/4/6/16），版权声明原样保留。
