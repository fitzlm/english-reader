# LinguiPro 静读

把网页上的英文，排成一本好书。

选中一段英文，右键选择「用静读打开」（或按 <kbd>⌥⇧R</kbd>、点工具栏图标选「打开静读」），原网页上会盖上一层阅读版式：
Literata 正文、1.85 倍行距，默认正文宽度 800px，参考 A4 纸的横向尺度；段间留白为 1.6em。每段累计达到 320 字符后，遇到下一个有效句末立即分段，不再把短尾段合并回去。网页用 `<br>` 写出的句末换行也会还原为有间距的段落。超出你词汇量的生词被轻轻划出，释义写在页边，
文末附一张生词表。按 <kbd>Esc</kbd> 回到原网页。

## 安装

还没有上架 Chrome 应用商店。可以直接从源码仓库加载，不需要先构建：

1. 克隆本仓库，或在 GitHub 上下载并解压代码：

   ```bash
   git clone https://github.com/fitzlm/english-reader.git
   ```

2. 在 Chrome 地址栏打开 `chrome://extensions`，打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择克隆或解压后的 `english-reader` **仓库根目录**。请选择其中直接包含 `manifest.json` 的目录，不要选 `src/`。
4. 安装后会自动打开欢迎页。选中示范段落，右键选择「用静读打开」即可试用。

需要 Chrome 120 或更新版本。日常使用源码目录时，不需要运行 `npm install` 或构建命令。修改插件代码后，回到 `chrome://extensions`，点击「LinguiPro 静读」卡片上的刷新图标；如果插件已在网页中打开，再刷新该网页。

也可以将插件打包成 zip：在仓库根目录运行 `npm run package`，生成 `dist/linguipro-reader-<版本>.zip`。将 zip 解压后，在「加载已解压的扩展程序」中选择解压出来、直接包含 `manifest.json` 的目录。

## 用法

| 想做什么 | 怎么做 |
|---|---|
| 打开阅读版式 | 选中文字 → 右键「用静读打开」；或 ⌥⇧R；或点工具栏图标 →「打开静读」 |
| 在原网页上直接查词 | 点工具栏图标，打开「本站点点词翻译」并允许访问该网站；之后单击网页正文里的英文单词即可看到释义 |
| 在原网页上直接翻译选中的文字 | 同上开启后，选中英文（一个词、一句话或几段都行），选区末尾会冒出小按钮「译」，点它就地看译文；与「用静读打开」互不影响 |
| 看生词释义 | 宽屏看右侧页边；把鼠标移到带下划线的词上看卡片；文末有完整生词表 |
| 查任意一个词 | 单击它（词库没有的词会现场机器翻译） |
| 看某段的中文译文 | 点击该段末尾的「译文」；再点可收起，失败时可重试 |
| 不想再看到某个词 | 卡片或生词表里点「认识了」（可撤销；设置页可放回） |
| 调词汇量、字号、字体、行宽、段落间距、背景 | 右上角 Aa |
| 只查一两个词 | 只选中这几个词再打开，直接弹出释义卡片 |

### 原网页点词翻译

默认关闭，按网站分别开启：点工具栏图标，打开「本站点点词翻译」，Chrome 会请求访问该网站的权限，允许后立即生效，
刷新、再次访问和重启浏览器后都保持开启。设置按协议和完整主机名记忆（`https://www.example.com` 不会连带开启其他子域）。

- 单击正文里的英文单词，旁边弹出词卡：先查 LinguiPro 词库，词库没有的词现场机器翻译，并标明来源；查过的词和阅读页一样记入查词记录
- 链接、按钮、输入框、可编辑区域、代码不响应；拖选、双击选词、按住修饰键点击不触发；不会拦截网页原有的点击
- 点外面、按 <kbd>Esc</kbd>、滚动页面或调整窗口时词卡收起；打开静读时暂停，关闭后恢复
- 暂不支持 iframe 内、Shadow DOM 内的文字，以及图片、Canvas、PDF 和浏览器内置页
- 关掉开关会停用脚本并交还该网站的访问权限；在 Chrome 的扩展菜单里撤销权限也会同步停用
- 菜单里会当场确认「当前页面点词已生效」；开着的网站上脚本没在运行（比如浏览器恢复的旧标签页）时，打开菜单会就地补上，仍不行再刷新页面

### 原网页选中文字翻译

和点词共用「本站点点词翻译」这一个开关，开启的网站上都能用：

- 选中英文（拖选、双击、三击、<kbd>Shift</kbd>+方向键扩选都行），光标那一端旁边冒出小按钮「译」：正向选择挂在末尾下方，反向选择挂在开头上方，放不下自动翻到另一侧
- 点按钮就地显示译文。选中的是单个英文单词，显示词卡（词库，没有就机器翻译，同点词，并记入查词记录）；短语、句子、连字符复合词、多段文字整段机器翻译（微软翻译），按段对照，一次请求
- 只做英文 → 中文；选中 1~3000 个字符、最多 40 段。中文、代码和标识符（`user_id`）、网址、邮箱不出按钮
- 输入框、可编辑区域、`pre` / `code` 里的选区，以及静读阅读层里的选区不出按钮；网页脚本改出来的选区不出按钮，键盘扩选、鼠标操作照常
- 按钮不拦截网页的任何事件，网页上的选区原样保留；译文卡里的文字也可以选中复制
- <kbd>Esc</kbd>、点别处、选区滚出视野时按钮和译文卡收起；译文很长时在卡内滚动，不长时鼠标停在卡上页面照常滚动
- 翻译失败会说明原因（限流时单独提示），点「重试」再来；这条路和「用静读打开」（右键菜单、<kbd>⌥⇧R</kbd>）互相独立，同时用也不冲突

### 生词是怎么判定的

后端 `POST /api/words/glossary` 返回正文里每个词形的原形、词频排名 `rank`、考纲档位 `level`：

- 难度 = min(词频排名, 考纲档位)，大于你的词汇量就算生词；两者都没有的按最生僻处理
- 词频表是按词形排的（benefits 和 benefit 各有排名），所以取词形与原形候选里最靠前的排名
- 考纲档位来自词库标签：小学 700、初中 1600、高中 3500、四级 4500、考研 5500、六级 6000、雅思 7000、托福 8000、GRE 12000
- 专有名词（句中大写、括号里大写、全大写缩写）、代码标识符（Node.js、camelCase）、外文碎片、两字母词不算生词

### 语境释义

词典给的是一串义项，第一个未必是文中的意思（calculus 的首个义项是「[医]结石」）。生词整理好后，插件把
「生词 + 所在句子」一次交给 `POST /api/ai/reader-gloss`，由模型给出**在这句话里**的意思，旁注和卡片里标着「语境」。
每篇先问开头 40 个生词，读到后面再补问，最多 3 批；每批消耗 1 次 LinguiPro 的 AI 次数，用完当天自动改用词典释义。
可以在设置页关掉。

## 账号

不登录也能用：插件会以游客身份向后端要一个临时 token（15 分钟有效，过期自动续）。
在设置页登录 LinguiPro 账号后，会同步你在 LinguiPro 测出的词汇量，AI 次数也更多。

## 隐私

用静读打开文字时，插件会把其中的单词（开启语境释义时还有生词所在的句子）发送到 LinguiPro 服务器。
只有点击某段的「译文」时，才会把该段原文发送到微软的在线翻译服务；不会自动翻译整篇文章。免费翻译服务可能限流或暂时不可用。
在开启了「本站点点词翻译」的网站上，单击某个词时只把这一个词发送到 LinguiPro 服务器，不上传网页内容。
选中文字后什么都不会发送；只有点了小按钮「译」，才会把选中的文字（最多 3000 字符）发送出去：单个单词发往 LinguiPro 服务器，其余发往微软的在线翻译服务。
插件不读取、不上传浏览记录，也不发送你没有选中或点击的内容。读取原网页靠 `activeTab` 临时授权；固定网络权限只用于访问 LinguiPro 和微软翻译服务。
只有你亲自开启点词翻译的网站才会获得常驻访问权限（Chrome 会先征得你同意），关闭后即交还；没有「读取所有网站」的权限。

## 开发

```
src/
  background.js      入口：右键菜单、快捷键、工具栏菜单 -> 抓选区 -> 盖阅读层；点词查询与站点开关的消息分发
  capture.js         注入网页：遍历实时 DOM，把选区抓成结构化块（不传 HTML）
  overlay.js         注入网页：closed shadow root 里的全屏 iframe，关闭后原样恢复
  reader/            阅读页（排版、生词标注、旁注排布、生词表、释义卡片）
  options/           设置页兼欢迎页
  popup/             工具栏菜单：本站点点词开关（含当前页面是否生效的确认）、打开静读、设置
  page/              原网页点词与选中翻译：内容脚本加载器、取词、选中翻译按钮、词卡与译文卡
  shared/            后端客户端、设置存储、纯文本逻辑
fonts/  icons/
tests/unit/          node --test 单测
tests/e2e/           Playwright：加载真实插件跑端到端（selection.spec 选中翻译、page-lookup.spec 点词、site.spec 菜单与站点开关、live-selection.spec 真实网站冒烟）
```

```bash
pnpm install
npm test                                 # 单测
npx playwright test reader               # 端到端（后端 mock）
LIVE=1 npx playwright test live          # 真实网站 + 线上后端（维基、PG、古腾堡、MDN、GitHub）：静读阅读层，以及原网页点词与选中翻译（live-selection）
npm run icons                            # 重新生成图标
npm run package                          # 打包 zip
```

后端接口在 `english-learning-fastapi` 仓库：`app/services/glossary_service.py`、`app/routers/words.py`。
服务器地址默认 `https://json-view.org/english`，可在设置页「高级设置」里改。
